# 项目上下文

## 已明确的目标

用户将 Armor Make 定义为给现有命令套一层壳、扩展其行为的通用工具。当前具体扩展为优先读取当前及父目录的配置；找到后定向原始命令，找不到则沿用原用户配置。

首版以 Node.js 实现，已有 Git、tea 工具适配器。通用核心不管理账号、维护项目身份根或重写原命令；工具适配可以按实际合同逐个增加。扩展其他能力先核对本次需求，避免把“命令包装工具”推成未提出的平台。

## 当前行为

- 每个工具独立寻找最近配置，不自动合并祖先配置，不在独立仓库的 .git 边界停止。
- 操作目录包含 Git 的 -C、clone 目标及 tea 的本地 --repo；显式 Git 元数据路径通过原始 Git 的只读定位处理。
- HOME 本身的 .config 保留为用户配置，其他祖先按序搜索。
- 已命中的配置文件损坏、类型错误或原生格式非法时报错；没有文件才继续查找或透传。
- Git 通过 GIT_CONFIG_GLOBAL 定向 global 来源，tea 通过 XDG_CONFIG_HOME 定向配置目录；原生 local、命令参数和认证环境仍可覆盖。
- 安装显式创建同名包装入口，已有非本工具命令受到保护。安装记录不含项目账号，卸载只删除归属和内容仍匹配的入口。

具体格式和用法以 [README](../../README.md)、命令 --help 和代码为准。术语定义保留在 [GLOSSARY.md](../../GLOSSARY.md)，不在本文件复制。

## 独立验收边界

代码和 CI 通过不证明全局入口已安装，也不证明后台服务使用入口。账号身份、Gateway PATH、运行中的 Worker、npm 发布等分别取得证据。

“必须始终使用 Ada”等账号要求是独立部署约束，当前配置查找功能不提供该保证。不要自动恢复旧的账号登记方案或悄悄改写原工具的认证规则。

本项目独立于 Ada 角色仓库。技能、AI 文档和命令实现都在本项目维护；不借本项目任务修改其他仓库、用户配置或服务。
