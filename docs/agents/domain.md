# 领域资料约定

采用单上下文布局。讨论产品概念、命名或接口时读取根 [GLOSSARY.md](../../GLOSSARY.md)；涉及已有架构取舍时按需读取 docs/adr/ 中相关记录。

当前不创建空 ADR 或多上下文目录。新决策同时满足“更改代价明显、脱离背景容易误解、存在真实取舍”时再记录 ADR，按 domain-modeling 技能中的 ADR-FORMAT.md 编写。

术语表只定义产品概念，代码结构、命令语法和当前状态放到对应 README 或规格中。术语与需求发生冲突时说明差异，以用户明确的新目标重新核对；不自动套用第三方技能的英文词汇替代已形成的产品语言。
